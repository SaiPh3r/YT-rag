# 🎥 YouTube Transcript Q&A with Gemini (LangChain + FAISS)

This project uses **LangChain**, **Google Gemini**, and **FAISS** to answer questions based on a YouTube video's transcript.  
It automatically fetches the transcript, chunks it, embeds it, and performs a **Retrieval-Augmented Generation (RAG)** process — giving you intelligent answers grounded in the video content.

---

## 🚀 Features

- Fetches **YouTube transcripts** automatically  
- Splits text into **semantic chunks**  
- Creates **embeddings using Gemini**  
- Stores them in a **FAISS vector database**  
- Uses **LangChain Runnables** for structured RAG pipeline  
- Answers any question contextually about the video  

---

## 🧠 Tech Stack

- **Python 3.10+**
- **LangChain**
- **Gemini API (Google Generative AI)**
- **FAISS**
- **YouTube Transcript API**
